## 📋 SOBRE O PROJETO

Este é um jogo de **Jokempo (Pedra, Papel e Tesoura)** desenvolvido em C#. 

O jogo permite que o usuário jogue contra o computador, acumule estatísticas e troque de jogador a qualquer momento.
